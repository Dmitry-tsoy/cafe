# ☕ Анализ продаж в кафе

## 📌 О проекте

Проект посвящён анализу продаж в кафе: очистке исходных данных, исследованию структуры продаж и поиску факторов, связанных с выручкой.

**Цель проекта:** определить, какие позиции меню и условия продаж формируют наибольшую выручку, и выявить возможности для её увеличения.

---

## 📊 Данные

Датасет содержит информацию о транзакциях кафе:

| Поле | Описание |
|---|---|
| `transaction_id` | Идентификатор транзакции |
| `item` | Позиция меню |
| `quantity` | Количество проданных единиц |
| `price_per_unit` | Цена за единицу |
| `total_spent` | Сумма транзакции |
| `payment_method` | Способ оплаты |
| `location` | Формат заказа: `In-store` / `Takeaway` |
| `transaction_date` | Дата транзакции |

В исходных данных присутствовали пропущенные и некорректные значения (`ERROR`, `UNKNOWN`).

---

## 🧹 Очистка и подготовка данных

В процессе подготовки данных:

- измене формат названия столбцов;
- `ERROR` и `UNKNOWN` заменены на пропуски;
- изменены типы данных;
- проверены дубликаты и пропущенные значения;
- часть пропусков восстановлена на основе зависимости  
  `total_spent = quantity × price_per_unit`;
- цена восстановлена по известной позиции меню там, где это было возможно;
- позиции меню восстановлены по цене при однозначном соответствии.

Для позиций с ценой **3 USD** и **4 USD** часть строк нельзя было однозначно отнести к конкретной позиции меню.

Поскольку среди известных наблюдений распределение соответствующих позиций по количеству транзакций и проданных единиц было близко к **50/50**, неопределённая выручка была распределена поровну между позициями одной ценовой группы только на агрегированном уровне.

---

## 🔎 Анализ

В рамках проекта исследованы:

- выручка по позициям меню;
- количество транзакций;
- количество проданных единиц;
- продажи по форматам `In-store` и `Takeaway`;
- структура продаж по способам оплаты;
- продажи по дням недели;
- динамика продаж по месяцам.

---

## 📈 Основные результаты

### Количество транзакций

Количество транзакций по позициям меню распределено относительно равномерно:

- **Coffee — 1 291** транзакция (максимум);
- **Smoothie — 1 096** транзакций (минимум);
- среднее — **≈ 1 190 транзакций** на позицию.

### Количество проданных единиц

Количество проданных единиц также распределено относительно равномерно:

- **Coffee — 3 904** единицы (максимум);
- **Smoothie — 3 336** единиц (минимум);
- среднее — **≈ 3 589 единиц** на позицию.

Существенной разницы в популярности позиций по количеству продаж не наблюдается.

### Выручка

Выручка между позициями различается заметнее.

Наибольшую долю общей выручки формируют:

1. **Salad — 21,4% (19 095 USD)**
2. **Sandwich — 17,0% (15 124 USD)**
3. **Smoothie — 16,6% (14 752 USD)**

При этом количество проданных единиц по позициям отличается относительно незначительно.

**Различия в выручке в большей степени связаны с ценой позиций, а не с существенной разницей в объёме продаж.**

### Другие факторы

Распределение продаж по способам оплаты и между форматами **In-store** и **Takeaway** существенно не отличается.

Также не выявлено выраженных различий в продажах по дням недели и месяцам. Заметной сезонности или временных закономерностей в рамках анализируемого периода не обнаружено.
